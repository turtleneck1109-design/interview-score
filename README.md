# 面试评分台

[在线使用](https://turtleneck1109-design.github.io/interview-score/) · [下载离线 HTML](https://github.com/turtleneck1109-design/interview-score/raw/refs/heads/main/docs/index.html)

免登录的面试评分网页。支持在线打开，也可下载 `docs/index.html` 双击离线使用。

## 功能

- 候选人添加、编辑、备注与删除确认。
- 每位候选人由一位面试官评分；面试官可添加、移除和恢复。
- 各环节默认折叠题目，可以直接打分，也可以选择题目、自拟题和记录回答。
- 0.5 分评分、实时总分、自动保存；正式提交后计入汇总。
- 内置题库、自建题库、JSON 模板下载、题库导入与完整导出。
- 普通面试及小闪电、摄影加试，遵循原评分模板。
- 面试名称和校区可修改；活动安排和结果通知可自行填写、修改或留空；支持手机与电脑布局。
- 评分包合并、成绩 CSV 导出与完整 JSON 备份。

## 数据与协作

网页不设账号、服务器数据库或云同步。候选人、回答和评分保存在当前浏览器的 localStorage 中，不上传到 GitHub 或网站服务器。不同设备、浏览器或网站地址的数据互相独立。

1. 负责人整理候选人名单，点击“导出名单”分发。
2. 各面试官导入名单，添加或选择自己的姓名，给分配的候选人评分。
3. 评分完成后提交，再导出“我的评分包”。
4. 负责人批量导入评分包，在“成绩汇总”查看和导出结果。

修改已提交评分会转为草稿，需要再次提交。移除面试官保留其评分，可在“已移除”中恢复。删除候选人会同时删除关联评分，操作前请核对。

“到场与备注”或“设置与备份”中的“活动安排与通知”用于填写本场面试共用的时间、地点和通知方式，不参与评分，默认留空。保存后刷新仍保留；名单和完整备份会携带这些设置，个人评分包不会覆盖负责人设置。同场面试导入较新版本会更新；旧版不会覆盖，同版本冲突或面试名称不同时保留本机设置并提示。

定期使用“完整备份”。清理浏览器数据或更换设备前先导出备份。由本地 HTML 转到在线网址时，先在原页面导出完整备份，再在在线页面导入。

## 题库模板

在网页“题库”中下载模板和说明。静态文件也在 `docs/题库导入模板.json` 与 `docs/题库模板填写说明.txt`。

内置题目来自提供的《2026上马面试题A》和《2026上马面试题B》，共 80 道。B 卷 49 道题中，17 道沿用已有相同或近似题目，新增 32 道。题库以“A卷”（31 道）、“B卷”（32 道）和“A/B卷”（17 道共有题）标注来源；搜索“A卷”或“B卷”时也包含共有题。原有 A 卷题目编号和内容保持不变，旧评分记录和备份仍可使用。B 卷开赛日期存在 12 月 6 日与 12 月 16 日两种写法，相关参考答案已标注待核对。活动日期、人数、地点及参考答案使用前应按实际活动更新。原始 Word、Excel 和实际面试数据不属于这个代码仓库。

## 开发与构建

需要 Node.js 22 或以上。

```sh
npm ci
npm run check
```

`npm run build` 将 React、图标和样式打包到 `docs/index.html`，无需运行时 CDN 或网络接口。`npm test` 检查保存、合并、评分、题库和成员管理。

- `app/desk.tsx`：界面和交互
- `app/style.css`：样式与响应式布局
- `lib/`：评分、存储、候选人、面试官和题库逻辑
- `offline.test.mjs`：功能检查
- `docs/`：构建后的可部署网页

GitHub Pages 可将 `main` 分支的 `/docs` 目录设为发布源。更新后运行 `npm run check`，提交源码与 `docs`，推送到 GitHub 即可更新网站。

修改评分、回答、选题、自拟题或面试备注后自动计时；成功提交后停止。再次修改已提交的记录会继续累计用时。每位候选人的用时独立保存，切换候选人或刷新页面不会清零；提交前按实际经过时间继续累计。仅切换环节、展开题目或查看记录不会启动计时。用时随备份保存，并在评分详情和 CSV 中显示；旧记录不补算历史用时。

页面右上角的「下载 HTML」可保存当前版本的独立离线页面，双击即可使用。下载文件仅包含程序和内置题库；候选人、评分、自建题库与设置请通过「完整备份」导出，并在离线页面中导入。

各环节的题目回答框默认收起，点击「记录回答」或「查看回答」展开；再次点击可收起，已填写内容保留并自动保存。

首次在浏览器中打开时，先填写面试官姓名再进入评分台，无需注册。姓名保存在本机，之后打开不再重复填写；可在「设置与备份」修改。旧版本已设置姓名的用户直接进入，仍使用默认「面试官 1」的用户需补填一次，原有评分与面试官编号保留。
