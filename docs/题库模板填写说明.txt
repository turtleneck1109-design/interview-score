面试评分台 · 题库导入模板填写说明

一、如何使用
1. 用文本编辑器打开“题库导入模板.json”，将三个示例替换成自己的题目；不要直接把说明文字写进 JSON。
2. 每个 { ... } 表示一道题。可复制题目对象以增加题目，用英文逗号分隔，最后一题后不要加逗号；不需要的示例可整条删除。
3. 保存为 UTF-8 编码的 .json 文件。
4. 打开最新版“上马面试评分台_免登录.html”，进入“题库”→“导入题库”，选择填好的 JSON。
5. 在“题库”中搜索新增题目；面试时会按所属环节及候选人类型显示。也可以在“设置与备份”中导入。

二、每道题需要的字段
id：唯一编号，建议以 custom- 开头，例如 custom-team-a-001。新增题目使用新编号，不要使用内置题库的 q01、q02 等编号。
category：所属环节代码，见下表。
group：适用对象代码，见下表。
text：题目内容，必须填写，最多 3000 字。请删除示例中的“【示例，请替换】”。
answer：参考答案或评分要点，最多 6000 字；没有参考答案时保留空字符串 ""，不要删除字段。

三、所属环节 category
intro         开场介绍（不计分）
feeling       活动感想 / 活动了解
thinking      活动思考 / 活动热情
response      应变能力
dialogue      情景对话
impression    综合印象（可选补充提问）
availability  到场确认（显示在“到场与备注”）
work          小闪电工作理解
scene         小闪电工作情景
photography   摄影评价
survey        其他调查（不计分）
closing       结束确认（显示在“到场与备注”）

四、适用对象 group
all           全体候选人
new           未参加过上马 / 半马
experienced   参加过上马 / 半马
lightning     小闪电
photo         摄影志愿者

搭配要求：work 和 scene 必须搭配 lightning；photography 必须搭配 photo。
例如，只给首次参加者的活动了解题：category 填 feeling，group 填 new。

五、文件外层结构
app 必须保持为 shangma-score-offline，formatVersion 保持为数字 2，type 保持为 bank。
所有题目放在 questions 数组里。members、candidates、evaluations 三个数组保持为空 []，不要删除。
示例不涉及候选人信息或评分，导入只添加题库。

六、格式与合并规则
使用英文双引号、英文冒号和英文逗号，不支持 JSON 注释。
题目中需要换行时写 \n；题目中如需英文双引号，写 \"，也可直接使用中文引号“”。
重复导入相同编号且内容完全相同的题目不会重复添加。
相同编号但内容不同会拒绝导入，不会覆盖旧题；更改已导入题目内容后，请给新内容分配一个新的编号。
新增题库只保存在当前浏览器；分发给其他面试官时，可使用“导出全部”或“导出名单”，由对方导入。

七、完整题库导出
“导出全部”包含内置题与自建题，可直接导入最新版评分台；相同内置题自动跳过。修改内置题内容时，请分配新的 custom- 编号，以作为新增题目导入。
